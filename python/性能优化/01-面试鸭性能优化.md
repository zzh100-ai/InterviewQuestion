### Q1: 2179. 什么是鸭子类型（duck typing）？

**难度**: 中等  

鸭子类型（duck typing）是一种动态类型检查的方法，广泛应用于动态语言如Python中。它的核心理念是："如果它像鸭子一样走路，并且像鸭子一样叫，那么它很可能就是一只鸭子"。从编程角度来看，鸭子类型关注对象的行为（方法和属性）而不是其实际类型。这样，使得编写更加灵活和简洁的代码成为可能。

### Q2: 2180. 为什么 Python 执行速度慢，如何改进？

**难度**: 中等  

Python 慢主要是三个原因：解释执行、动态类型和 GIL。

1）解释执行：C/C++ 编译完就是机器码，CPU 直接跑。Python 每次运行都要把源码翻译成字节码，再由解释器一条条执行，中间多了一层翻译开销

2）动态类型：a = 1 这行代码，Python 运行时才知道 a 是整数。每次操作都要先查类型、再找对应的方法，比静态类型语言多了大量运行时检查

### Q3: 2181. 如何分析 Python 代码的执行性能？

**难度**: 中等  

Python 性能分析的核心思路是先定位瓶颈，再针对性优化。不要凭感觉猜哪里慢，得用工具量出来。

常用的分析工具分三类：

1）时间分析：cProfile 看函数级耗时，line_profiler 看每行代码耗时

2）内存分析：memory_profiler 看内存占用变化，tracemalloc 追踪内存分配来源

3）快速计时：timeit 模块做微基准测试，比手写 time.time() 靠谱
