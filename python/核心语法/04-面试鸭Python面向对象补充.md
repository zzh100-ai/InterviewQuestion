### Q1: 2170. 你知道哪些 Python 的编码规范？

**难度**: 中等  

PEP 8 是 Python 官方的编码风格指南，所有 Python 项目都建议遵循。

核心要点包括：

1）缩进用 4 个空格，别用 Tab，混用会报错

2）每行不超过 79 个字符，长表达式要换行

3）类和顶级函数之间空两行，类内方法之间空一行

4）命名规范：变量和函数用 snake_case，类名用 CamelCase，常量全大写加下划线

5）导入顺序：标准库、第三方库、本地模块，三组之间空一行

### Q2: 2171. Python 的类和对象有什么区别？

**难度**: 中等  

类（Class）和对象（Object）是面向对象编程（OOP）的两个核心概念。在Python中：

1）类 是一种模板，它定义了对象的属性和行为。

通俗地说，类就像一个蓝图，而对象则是根据这个蓝图制造出来的具体“产品”。

### Q6: 2175. 什么是 Python 面向对象的抽象特性？

**难度**: 中等  

面向对象编程（OOP）的四大基本特性之一就是抽象。抽象是指将复杂的系统隐藏在一个简单的接口后面，只呈现出必要的功能细节，而将具体的实现细节隐藏起来。通过抽象，可以使代码更加模块化、可维护性更好，也更符合人类的思维模式。

### Q8: 2177. 什么是 Python 面向对象的多态特性？

**难度**: 中等  

Python的面向对象编程（OOP）中的多态特性，指的是不同对象对同一方法的不同实现。在应用中，多态性可以让我们在不改变代码主体结构的情况下，使用不同的对象来实现相同的接口或方法。这使得代码更具灵活性和可扩展性。

简单一点来说，多态就是“同一操作，作用于不同的对象，可以有不同的解释与实现”，这在Python中通常通过继承和接口来实现。
