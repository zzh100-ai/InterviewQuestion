### Python 中类变量和实例变量有什么区别？

类变量定义在类体中，所有实例共享同一份数据；实例变量定义在 `__init__` 或其他实例方法中，通过 `self` 绑定，每个实例独立持有。

```python
class Dog:
    species = "Canis familiaris"  # 类变量，所有狗共享

    def __init__(self, name):
        self.name = name  # 实例变量，每条狗自己的名字

d1 = Dog("旺财")
d2 = Dog("来福")
print(d1.species)  # Canis familiaris
print(d2.species)  # Canis familiaris
Dog.species = "犬科"
print(d1.species, d2.species)  # 犬科 犬科（都跟着变）
```

> **注意**：类变量是可变对象时，通过实例修改会影响所有实例，因为实际上直接修改了类变量指向的那个对象。

```python
class Team:
    members = []

t1 = Team()
t2 = Team()
t1.members.append("张三")  # 没有给实例赋值，操作的是类变量
print(t2.members)  # ['张三']——t2 也被影响了
```

### `__new__` 和 `__init__` 有什么区别？

`__new__` 是静态方法，负责创建对象并返回实例；`__init__` 是实例方法，负责初始化已经创建好的对象。调用顺序是先 `__new__` 后 `__init__`。

```python
class Demo:
    def __new__(cls, *args, **kwargs):
        print("创建对象")
        instance = super().__new__(cls)
        return instance  # 必须返回实例

    def __init__(self, value):
        print("初始化对象")
        self.value = value

d = Demo(42)
# 输出：
# 创建对象
# 初始化对象
```

如果 `__new__` 返回的不是当前类的实例，`__init__` 就不会被调用。

### Q3: @staticmethod 和 @classmethod 的区别？

| | @staticmethod | @classmethod |
|---|---|---|
| 第一个参数 | 无隐含参数 | cls（类本身） |
| 访问类变量 | 需通过类名 | 通过 cls 参数 |
| 访问实例变量 | 不可以 | 不可以 |
| 继承表现 | 不感知调用者 | cls 指向实际调用者 |

```python
class Base:
    name = "Base"

    @staticmethod
    def static_hello():
        return f"hello from {Base.name}"  # 写死类名

    @classmethod
    def class_hello(cls):
        return f"hello from {cls.name}"  # cls 随继承变

class Child(Base):
    name = "Child"

print(Child.static_hello())  # hello from Base（没有感知到继承）
print(Child.class_hello())   # hello from Child（cls = Child）
```

### Q4: Python 中的 " 鸭子类型 " 是什么意思？

不关心对象的具体类型，只关心它有没有你需要的方法和属性。" 走起来像鸭子、叫起来像鸭子，那它就是鸭子 "。

```python
class Duck:
    def quack(self):
        print("嘎嘎嘎")

class Person:
    def quack(self):
        print("我学鸭子叫")

def make_it_quack(thing):
    thing.quack()  # 不检查类型，只要对象有 quack 方法就行

make_it_quack(Duck())   # 嘎嘎嘎
make_it_quack(Person()) # 我学鸭子叫
```

Python 的很多协议（迭代器、上下文管理器等）都是靠鸭子类型实现的，只要实现了对应方法就能配合 `for` / `with` 使用。

## 继承与 MRO

### Q5: 什么是 MRO？Python 3 和 Python 2 有什么区别？

MRO（Method Resolution Order）决定了多继承时方法和属性的查找顺序。

**Python 2 旧式类**：深度优先。如果两个父类有同名方法，第一个被深度遍历到的会被调用，结果可能不是直觉预期。

**Python 3 新式类**：C3 线性化算法，保证：

1. 子类总是在父类前面
2. 父类的声明顺序被尊重
3. 所有父类的方法都只会被访问一次

```python
class A: pass
class B(A): pass
class C(A): pass
class D(B, C): pass

print(D.__mro__)
# D -> B -> C -> A -> object
```

可以用 `类名.__mro__` 或 `类名.mro()` 查看 MRO。C3 算法保证不会出现 " 菱形继承 " 中的重复调用问题。

### Q6: `super().__init__()` 解决什么问题？

在多继承场景下，直接写 `父类名.__init__(self)` 会导致某个父类被初始化多次（尤其是菱形继承），而 `super()` 按照 MRO 顺序保证每个类只初始化一次。

```python
class A:
    def __init__(self):
        print("A init")
        super().__init__()

class B(A):
    def __init__(self):
        print("B init")
        super().__init__()

class C(A):
    def __init__(self):
        print("C init")
        super().__init__()

class D(B, C):
    def __init__(self):
        print("D init")
        super().__init__()

D()
# 输出顺序：D -> B -> C -> A
# 每个类的 __init__ 只执行一次
```

### Q7: 新式类和旧式类的核心差异？

| 特性 | 旧式类（Python 2） | 新式类（Python 3） |
|------|---------------------|---------------------|
| 继承 | 不继承 object | 默认继承 object |
| MRO 算法 | 深度优先 | C3 线性化 |
| `super()` | 不支持 | 支持 |
| `__slots__` | 不支持 | 支持 |
| property | 不支持 | 支持 |
| `type` vs `class` | `type(A())` = instance | `type(A())` = A |

Python 3 只有新式类，无需关心这个问题，但老项目迁移时常被问到。

## 元类与高级特性

### Q8: 什么是元类（metaclass）？什么场景会用到？

元类是 " 类的类 "，控制类的创建过程。`type` 就是 Python 内置的元类，你定义的每个类都是 `type` 的实例。

```python
# type 作为元类动态创建类
MyClass = type('MyClass', (object,), {'x': 42, 'hello': lambda self: 'hi'})
obj = MyClass()
print(obj.x)      # 42
print(obj.hello()) # hi
```

**典型应用场景**：

* **ORM**：Django 的 Model 通过元类自动将类属性映射为数据库字段
* **API 注册**：用元类自动收集所有子类，实现插件式架构
* **单例模式**：在 `__call__` 中控制实例的创建

```python
# 最简单的自定义元类示例
class Meta(type):
    def __new__(cls, name, bases, dct):
        dct['created_by_metaclass'] = True
        return super().__new__(cls, name, bases, dct)

class MyClass(metaclass=Meta):
    pass

print(MyClass.created_by_metaclass)  # True
```

### Q9: 单下划线和双下划线在 Python 中分别代表什么？

| 写法 | 含义 | 说明 |
|------|------|------|
| `_foo` | 约定上的私有 | 一种代码规范，表示 " 不应直接访问 "，但实际上仍可访问 |
| `__foo` | 名称改写（name mangling） | 解释器自动重命名为 `_类名__foo`，防止子类无意覆盖 |
| `__foo__` | 特殊方法/魔术方法 | Python 内部协议方法，如 `__init__`、`__str__`，不应自定义此类名称 |

```python
class Parent:
    def __init__(self):
        self._private = "约定私有"
        self.__secret = "名称改写"

class Child(Parent):
    def __init__(self):
        super().__init__()
        self.__secret = "子类的"

c = Child()
print(c._private)        # 约定私有（可访问，但不推荐）
print(c.__secret)        # 子类的
print(c._Parent__secret) # 名称改写（仍然能通过改写后的名字访问到）
```

### Q10: 什么是 Python 自省（introspection）？

自省是指在运行时获取对象的类型、属性、方法等信息的能力。Python 在这方面非常强大。

```python
# 常用自省工具
type(obj)             # 获取类型
dir(obj)              # 列出所有属性和方法
getattr(obj, 'attr')  # 获取属性值
hasattr(obj, 'attr')  # 判断是否有该属性
isinstance(obj, cls)  # 判断是否为某类实例
issubclass(cls, base) # 判断是否为某类子类
callable(obj)         # 判断是否可调用
inspect.getsource(fn) # 查看函数源码
id(obj)               # 获取内存地址
```

### Q11: Python 中的闭包是什么？

闭包是一个函数，它能记住并访问定义时所在的外部作用域中的变量，即使外部函数已经执行完毕。

三个必要条件：

1. 必须有函数嵌套
2. 内层函数引用外层函数的变量
3. 外层函数返回内层函数

```python
def make_multiplier(n):
    def multiplier(x):
        return x * n  # n 来自外层作用域，被闭包记住
    return multiplier

times3 = make_multiplier(3)
times5 = make_multiplier(5)
print(times3(10))  # 30
print(times5(10))  # 50
```

## 设计模式

### Q12: 请手写单例模式（至少两种写法）

**方式一：使用 `__new__`**

```python
class Singleton:
    _instance = None

    def __new__(cls, *args, **kwargs):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance

a = Singleton()
b = Singleton()
print(a is b)  # True
```

**方式二：使用装饰器**

```python
def singleton(cls):
    instances = {}
    def get_instance(*args, **kwargs):
        if cls not in instances:
            instances[cls] = cls(*args, **kwargs)
        return instances[cls]
    return get_instance

@singleton
class Database:
    pass
```

**方式三：使用模块导入**

模块在 Python 中是天然的单例——无论被 import 多少次，模块代码只执行一次，所有导入者共享同一个模块对象。把全局状态放在模块级别即可。

**方式四：使用元类**

```python
class SingletonMeta(type):
    _instances = {}
    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            cls._instances[cls] = super().__call__(*args, **kwargs)
        return cls._instances[cls]

class Logger(metaclass=SingletonMeta):
    pass
```

### Q13: Python 中为什么没有函数重载？

Python 不需要函数重载，原因有两点：

1. **动态类型**：参数没有类型声明，同一个函数天然可以接受任意类型的参数
2. **默认参数**：用 `def func(a, b=None, c=0)` 就能实现参数个数的灵活性

如果确实需要根据参数类型分发，可以用 `functools.singledispatch`（3.4+ 内置的泛型函数分发）：

```python
from functools import singledispatch

@singledispatch
def process(arg):
    raise NotImplementedError

@process.register(int)
def _(arg):
    return f"整数: {arg}"

@process.register(str)
def _(arg):
    return f"字符串: {arg}"
```
