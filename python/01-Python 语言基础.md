## Python 概述

### Q1: 什么是 Python？为什么它会这么流行？

Python 是一门设计上很注重可读性的编程语言，代码写出来接近自然语言，缩进强制规范让结构清晰。这种简洁风格降低了入门门槛，初学者几天就能上手写脚本。

它流行的关键在于生态够全。科学计算有 NumPy 和 Pandas，机器学习靠 PyTorch 和 TensorFlow，Web 后端有 Django 和 Flask，自动化脚本更是随手就来。几乎每个热门领域都有成熟框架顶着，开发者不用重复造轮子。

1）语法糖多，比如列表推导式一行搞定循环过滤
```python
squares = [x**2 for x in range(10) if x % 2 == 0]
```
2）解释型语言，跨平台运行，改完代码立即执行
3）C 扩展支持让性能敏感部分可以外挂模块，兼顾效率

社区活跃度极高，PyPI 上超 40 万包，遇到问题基本都能搜到解决方案。像数据分析团队用 Jupyter + Python 做全流程处理，从清洗到可视化一气呵成。企业端也买账，Instagram 用 Django 扛住千万级日活，说明它不只适合小项目。

### Q2: Python 有哪些特点和优点？

Python 的设计哲学是"优雅、明确、简单"，它的特点和优点主要体现在开发效率和生态上。

语法简洁直观，强制缩进让代码结构清晰，省去了大量括号和分号。写同样功能的逻辑，Python 通常比 Java 或 C++ 少 30% 到 50% 的代码量，适合快速原型开发。

动态类型系统让变量无需声明类型，用起来灵活，但大型项目里容易出错，需要靠测试和类型注解（如 typing 模块）来补足。

它有极强的标准库，比如 `os`、`json`、`http` 这些开箱即用，做 Web 用 Flask 或 Django，搞数据分析上 Pandas 和 NumPy，机器学习直接上 PyTorch 或 TensorFlow，基本主流场景都有轮子。

1）胶水语言，能轻松调用 C/C++ 库
2）社区活跃，第三方包丰富，pip 安装几乎覆盖所有常见需求
3）广泛用于自动化脚本、数据处理、AI、Web 后端、爬虫等

不适合硬实时或高并发长连接服务，比如网关或消息中间件，这种场景 Go 或 Java 更稳。

### Q3: Python 有哪些局限性？

Python 的短板主要集中在性能和并发模型上，这跟它的设计取舍直接相关。

1）**执行效率问题**：Python 是解释型语言，代码逐行解释执行，没有编译成机器码。像数值计算、频繁循环这种场景，比 C/C++ 慢 10 到 100 倍很常见。虽然有 Cython 或 Numba 可以局部加速，但核心瓶颈在解释器本身。

2）**GIL（全局解释器锁）限制并发**：GIL 是 CPython 解释器的机制，它让同一时刻只有一个线程执行 Python 字节码。这意味着多线程在 CPU 密集型任务中根本发挥不了多核优势。想真正并行得靠 multiprocessing，但进程间通信成本高，内存不共享。

3）**移动和嵌入式支持弱**：不像 Java 有 Android SDK，Python 在移动端基本没戏。Kivy 这类框架尝试过，但生态和性能都撑不起来。嵌入式设备资源有限，CPython 解释器本体就十几 MB，压根不适合塞进 MCU。

4）**打包和分发麻烦**：pyinstaller 打包出来的应用动辄几十 MB，启动还慢。不同系统依赖的动态库容易出问题，尤其是涉及 numpy、pandas 这种带 native extension 的包。

5）**类型系统松散**：虽然 3.5+ 引入了 type hint，但属于运行时可选检查。不像 Go 或 Rust 那样强制编译期类型安全，团队做大项目时容易写出隐蔽 bug，重构也提心吊胆。

### Q4: 请列举一些 Python 的应用场景

1）**Web 开发**是常见方向，用 Django 或 Flask 能快速搭后台服务。比如知乎早期就是基于 Django 构建的，这类框架帮你搞定了路由、ORM 和安全机制，让你专注业务逻辑。

2）**数据处理和分析**也是一大块，配合 pandas、numpy 这些库，能高效处理百万级行的数据清洗和统计。加上 matplotlib 或 seaborn，可视化图表也能直接出。

3）**机器学习和 AI** 领域 Python 基本是首选。TensorFlow 和 PyTorch 都是 Python 优先的接口设计，研究者写模型不用纠结底层实现，几行代码就能定义神经网络。

4）**自动化脚本**是小但高频的用法。比如批量重命名文件、定时抓日志、自动发邮件，用 os、shutil、smtplib 几个标准库就能搞定，开发成本特别低。

5）**科学计算和工程仿真**也有身影，像 SciPy 和 SymPy 支持积分、微分方程求解，常被用于物理或数学建模场景。

6）**测试和运维工具链**里也常见，比如 Ansible 就是纯 Python 写的配置管理工具，通过 SSH 控制上千台服务器，脚本容易写也容易维护。

## 变量与标识符

### Q5: Python 中如何声明多个变量并赋值？

Python 里声明多个变量并赋值，其实就两种常见写法，看你是想赋相同值还是不同值。

如果多个变量要赋同一个值，比如 a、b、c 都等于 10，可以直接连等：
```python
a = b = c = 10
```
这种写法三个变量指向同一个对象，在数字、字符串这种不可变类型上没问题，但要是换成列表，就得小心了，因为改一个会牵连其他变量。

更常用的是序列解包，一次性把多个值拆开赋给多个变量：
```python
x, y, z = 1, 2, 3
```
右边可以是元组、列表，只要能迭代且长度匹配就行。这种写法在交换变量时特别方便：
```python
x, y = y, x  # 不用临时变量就完成了交换
```
还支持扩展解包，用 `*` 接收多余元素：
```python
first, *middle, last = [1, 2, 3, 4, 5]
# first=1, middle=[2,3,4], last=5
```

### Q6: 什么是 Python 元组的解封装？

Python 元组的解封装指的是把元组里的元素按顺序赋值给多个变量。写代码时很常见，比如函数返回多个值，你就可以用这个语法一口气接住。

1）假设有个元组 `result = ('Alice', 25, 'Engineer')`，你可以直接写：
```python
name, age, job = result
```
这三个变量会分别拿到元组里的对应值。这种写法简洁，也比通过索引取值更易读。

2）解封装不局限于元组，只要是可迭代对象都能这么干，比如列表、字符串。但元组最典型，因为它是不可变的，语义上更适合用来表示一组固定字段。

3）如果变量数量和元组长度对不上，会抛出 `ValueError`。比如左边两个变量，右边三个元素，Python 搞不定就会报错。

4）有时候你只关心部分值，可以用下划线 `_` 占位，表示忽略某个元素：
```python
name, _, job = result  # 只想要 name 和 job
```

5）还支持 `*` 操作符收集多余元素：
```python
first, *rest = (1, 2, 3, 4)
# first = 1, rest = [2, 3, 4]
```

### Q7: 请介绍 Python 中变量的作用域？

Python 里的变量作用域决定了在哪个位置能访问到某个变量。这个规则其实就靠一套叫 LEGB 的查找顺序来控制。

1）**L（Local）**指的是当前函数内部。你在一个函数里用 `x = 10` 定义的变量，就只在这个函数里生效。

2）**E（Enclosing）**是外层函数的作用域。比如嵌套函数，内层函数可以读取外层函数定义的变量。

3）**G（Global）**是全局作用域，也就是模块文件顶层定义的变量，任何函数都能读它。

4）**B（Built-in）**是内置作用域，像 `print`、`len` 这些不用导入就能用的名称。

查找时从近到远：先看局部有没有，再往外层函数找，接着是全局，最后查内置。但赋值行为会改变这一逻辑——只要函数内部对变量用了 `=` 赋值，默认就被当成局部变量，除非你用 `global` 或 `nonlocal` 明确声明。

```python
x = "global"
def outer():
    x = "enclosing"
    def inner():
        nonlocal x
        x = "modified"
    inner()
```
这里 `nonlocal` 告诉解释器别创建新的局部变量，而是去外层找 `x`。要是没这句，`x = "modified"` 就会在 inner 里新建一个局部变量，外层压根不改。

### Q8: 说明 Python 中标识符的命名规则

Python 的标识符命名看着简单，其实有几条硬性规定得遵守。

标识符就是变量名、函数名、类名这些你自己起名字的地方。首先，只能用字母、数字和下划线，而且第一个字符不能是数字。比如 `name`、`user_age` 都行，但 `2name` 就不行。中文字符其实也可以作为开头，比如 `姓名 = "张三"`，语法上是合法的，但一般不推荐，团队协作容易出问题。

Python 对大小写敏感，`myName` 和 `myname` 是两个不同的标识符。另外，不能用关键字当标识符，比如 `if`、`for`、`class` 这些，编辑器通常会高亮提示。

还有一个约定俗成的规则：以下划线开头的名字有特殊含义。单下划线 `_name` 表示内部使用，不是 public API；双下划线 `__name` 会触发名称改写（name mangling），主要用于类的私有属性；前后都双下划线的像 `__init__` 是系统定义的特殊方法，别自己乱造这种名字。

总的来说，合法只是第一步，写代码还得考虑可读性。一般用小写字母加下划线的组合，比如 `user_list`、`get_config`，类名则用大驼峰 `UserProfile`，这是社区普遍接受的风格。

### Q9: Python 是否区分大小写？

Python 是区分大小写的，从变量名、函数名到类名，大小写不同就代表不同的标识符。

比如定义一个变量 `name = "Alice"`，再用 `Name` 或 `NAME` 去访问，解释器会报 `NameError`，因为它认为这是三个完全不同的名字。函数也一样：

```python
def say_hello():
    print("Hello")
# 调用 say_Hello() 会报错，压根找不到这个函数
```

类名遵循同样的规则。定义 `class MyClass:` 后，写成 `myclass` 就没法实例化它。模块导入也是如此，`import MyModule` 和 `import mymodule` 可能指向不同文件。

### Q10: 为什么 Python 不建议使用下划线开头的标识符？

Python 里以下划线开头的标识符不是语法强制的访问控制，而是一种约定，用来表达属性或方法的"内部使用"意图。

1）**单下划线 `_name`**：表示这个变量、函数或方法是内部实现细节，外部代码尽量别碰。比如模块里的辅助函数，写 `_parse_config()` 就是在说"我是工具人，请模块外的朋友无视我"。`from module import *` 会跳过它，但普通导入或直接引用还是能访问。

2）**双下划线 `__name`**：这会触发名称改写（name mangling），在类中定义 `__x`，实际会被解释器改成 `_ClassName__x`。这是为了防止子类意外覆盖父类的私有属性。注意，它依然不是真正的私有，只是换个名字让你调用起来没那么顺手。

3）**前后双下划线 `__name__`**：这是系统定义的魔术方法，比如 `__init__`、`__len__`。你可以在自定义类中实现它们来支持语言特性，但不要自己造这种名字。

```python
class User:
    def __init__(self, name):
        self._age = 0      # 内部状态
        self.__id = 123    # 触发 name mangling

    def _validate(self):   # 内部方法
        return True
```

真正想隐藏？压根不导出或者用闭包/描述符更靠谱。下划线只是沟通工具，不是安全机制。

## 运算符

### Q11: Python 中 is 和 == 有什么区别？

`is` 和 `==` 看起来都是比较，但它们干的事完全不是一回事。

`==` 比的是值，也就是两个对象的内容是不是一样。比如两个字符串 `"hello"`，哪怕它们是不同地方创建的，内容一样，`==` 就返回 `True`。

而 `is` 比的是身份，也就是这两个变量是不是指向内存中的同一个对象。它判断的是 `id(a) == id(b)`，也就是底层的对象地址是否一致。

```python
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)  # True，内容相同
print(a is b)  # False，是两个不同的列表对象
```

但有些情况下，Python 会对小整数或短字符串做缓存：
```python
a = 256
b = 256
print(a is b)  # True，小整数在 [-5, 256] 被缓存
a = 257
b = 257
print(a is b)  # 可能是 False，不一定被缓存
```

所以一般情况下，判断值相等用 `==`，只有当你明确想确认两个变量是否指向同一个对象时才用 `is`。比如判断是不是 `None`，就该用 `if x is None`，因为 `None` 是单例，这种写法更安全也更快。

### Q12: Python 中的 != 和 is not 运算符有什么区别？

`!=` 和 `is not` 看着都是做"不等于"判断，但它们比的压根不是一回事。

`!=` 比的是值。只要两个对象的内容相等，哪怕它们是不同的实例，结果就是 `False`。比如两个列表 `[1,2,3] != [1,2,3]` 结果是 `False`，因为值一样。

而 `is not` 比的是身份，也就是内存地址。它只关心这两个变量是不是指向同一个对象。

```python
a = [1, 2, 3]
b = [1, 2, 3]
print(a != b)      # False，值相等
print(a is not b)  # True，不是同一个对象
```

一般情况下，比较数值、字符串内容就用 `!=`。只有当你明确想确认是不是同一个对象实例时才用 `is not`，比如判断是否不是 `None`：

```python
if x is not None:
    ...
```

简单说：`!=` 看内容，`is not` 看是不是同一个东西。

### Q13: 什么是 Python 的身份运算符？

Python 的身份运算符用于判断两个变量是否指向同一个对象，也就是它们在内存中的位置是否相同。这和比较值是否相等是两回事。

1）`is` 和 `is not` 就是身份运算符。`a is b` 返回 `True` 仅当 a 和 b 实际上是同一个对象，`is not` 是它的否定。

2）它底层比较的是对象的 id，也就是 `id(a) == id(b)`。你可以把 id 理解成对象在内存中的地址编号。

3）别把它和 `==` 混了。`==` 比较的是值，而 `is` 比较的是"是不是同一个东西"。

```python
a = [1, 2]
b = a
c = [1, 2]
print(a is b)  # True，b 是 a 的引用
print(a is c)  # False，c 是另一个对象
print(a == c)  # True，值一样
```

一般你用 `is` 最多的场景是判断是否为 `None`，比如 `if obj is None:`。这是标准写法，因为 `None` 是单例，不会有两个 `None` 对象。

### Q14: 什么是 Python 的成员运算符？

Python 的成员运算符用来判断一个元素是否存在于某个容器类型中，主要有两个：`in` 和 `not in`。它们返回布尔值，常用于字符串、列表、元组、集合和字典这类可迭代对象。

```python
fruits = ['apple', 'banana', 'orange']
print('banana' in fruits)   # True
print('grape' not in fruits) # True
```

查字典时，默认是判断键（key）是否存在，而不是值。
```python
d = {'name': 'Alice', 'age': 25}
print('name' in d)  # True
print(25 in d)      # False，因为 25 是值，不是键
```

对于字符串，`in` 判断的是子串是否包含。
```python
print('he' in 'hello')  # True
```

这玩意底层其实是调用对象的 `__contains__` 方法。你自定义的类如果想支持这个操作，实现这个方法就行。
```python
class MyContainer:
    def __init__(self, data):
        self.data = data
    def __contains__(self, item):
        return item in self.data
```

集合（set）和字典的查找效率是 O(1)，用 `in` 很快；而列表、元组这种是线性扫描，数据一多就慢。

### Q15: 什么是 Python 的关系运算符？

Python 的关系运算符用来比较两个值的大小或是否相等，结果是布尔类型 `True` 或 `False`。这些运算符不会改变原始数据，只做判断。

1）`==` 判断两边值是否相等。注意不要和赋值符号 `=` 搞混。
2）`!=` 判断两边值是否不相等。
3）`<` 和 `>` 分别表示小于和大于。
4）`<=` 和 `>=` 是小于等于和大于等于。

```python
score = 85
if score >= 60:
    print("及格")
```

所有关系运算符的优先级低于算术运算符，所以像 `a + 1 > b - 2` 这种表达式会先算加减，再做比较。

### Q16: 什么是 Python 的赋值和算术运算符？

**算术运算符**就是加减乘除这些。`+` 做加法，`-` 做减法，`*` 是乘法，`/` 是浮点除法（比如 `7 / 2` 得 `3.5`）。要想整除，用 `//`（`7 // 2` 结果是 `3`）。取余用 `%`（`7 % 3` 是 `1`）。幂运算用 `**`（`2 ** 3` 就是 `8`）。

这些运算符不光能用于数字，还能用在其他类型上。比如字符串可以用 `+` 拼接，`'a' + 'b'` 得 `'ab'`；列表也能用 `+` 合并。

**赋值运算符**最基础的是 `=`，把右边的值给左边变量。还有复合赋值，比如 `+=`、`-=`、`*=`，它们能简化写法。`x += 3` 等价于 `x = x + 3`，既读又写一次变量。

```python
count = 0
count += 1  # 相当于 count = count + 1
```

注意一点，Python 没有 `++` 或 `--` 自增自减操作符，想加一就得写 `+= 1`。

### Q17: 解释 Python 中 //、％ 和 ** 运算符

`//` 是向下取整的除法，比如 `7 // 3` 结果是 `2`，而 `-7 // 3` 是 `-3`，注意它不是简单地截断小数，而是向负无穷方向取整。这点和很多语言不同，容易出错。

`%` 是取模运算，结果的符号只取决于右操作数。例如 `-7 % 3` 得到 `2`，因为 Python 的 `%` 和 `//` 是配套设计的，满足 `(a // b) * b + (a % b) == a` 这个恒等式。这个特性在做循环索引、哈希分片时特别有用。

`**` 是幂运算，`2 ** 10` 就是 1024，支持小数次幂和负数次幂，比如 `9 ** 0.5` 算平方根，结果是 `3.0`。它优先级高于加减乘除，但低于括号。

这三个运算符在数学计算、算法题里经常一起出现。比如快速幂可以配合 `//` 和 `%` 实现：
```python
def pow_mod(x, n, mod):
    if n == 0:
        return 1
    half = pow_mod(x, n // 2, mod)
    return (half * half * (x if n % 2 else 1)) % mod
```

### Q18: 什么是 Python 的位运算符？

Python 的位运算符直接对整数的二进制位进行操作，效率高，在底层计算、权限控制、数据压缩等场景用得上。

1）`&` 按位与：两个对应位都为 1 时结果才为 1。比如权限系统里，用一个数表示多个权限位，`perm & READ_FLAG` 就能判断是否有读权限。

2）`|` 按位或：任一位为 1 结果就为 1。常用于权限合并，比如 `perm | WRITE_FLAG` 给用户追加写权限。

3）`^` 按位异或：两位不同结果为 1，相同为 0。有个经典用法是不借助临时变量交换两个数：
```python
a = a ^ b
b = a ^ b
a = a ^ b
```

4）`~` 按位取反：每个二进制位 0 变 1、1 变 0。注意这是带符号的，`~x` 等价于 `-x-1`。

5）`<<` 和 `>>` 是左右移位。左移一位相当于乘 2，右移一位相当于除以 2（向下取整）。比如高性能计算中常用 `n << 3` 代替 `n * 8`。

这些运算符处理的是补码形式的二进制，所以负数要小心。像 Redis 的布隆过滤器实现就大量用了位运算来做快速判存，毕竟直接操作 bit 最省空间也最快。

### Q19: 什么是 Python 的逻辑运算符？

Python 的逻辑运算符用来组合或反转布尔表达式的值，主要是 `and`、`or`、`not` 这三个。

1）`and` 要求两边都为真，结果才为真。比如 `x > 0 and x < 10`，只有 x 在 0 到 10 之间时才返回 True。一旦左边为 False，右边压根不执行，这叫**短路求值**。

2）`or` 是只要有一个为真就行。像 `x < 0 or x > 10`，x 只要超出范围就成立。如果左边已经为 True，右边就不跑了。

3）`not` 是取反，`not True` 就是 False。它优先级最低，一般建议用括号明确意图。

这些运算符不一定要返回布尔值，而是返回实际操作的值。比如 `'a' or 'b'` 返回 `'a'`，因为空字符串以外的值都算 True，所以 and 和 or 会直接返回操作数本身。

这特性常被用来做默认值赋值：
```python
name = input_name or 'default'  # 如果 input_name 为空就用 default
```

## 控制流

### Q20: Python 中 break、continue、pass 有什么作用？

`break` 是用来直接跳出当前循环的。比如你在 for 或 while 循环里，条件满足了想立刻停止，就用 break，后面剩下的迭代压根不执行了。

`continue` 是跳过当前这一次循环的剩余语句，直接进入下一轮循环。适合在某些条件下不想处理当前数据，但又不希望终止整个循环的情况。

`pass` 是个空操作语句，当语法上需要一条语句但实际不需要做任何事的时候就用它占位。比如写函数骨架时还没实现细节，先 pass 顶着，不然 Python 会报缩进错误。

```python
for i in range(5):
    if i == 2:
        continue
    if i == 4:
        break
    print(i)
# 输出是 0, 1, 3。因为 i=2 时跳过了 print，i=4 时循环直接结束。
```

别把 `break` 和 `return` 搞混了，`return` 是退出函数，`break` 只退循环。在嵌套循环中，`break` 只跳出最内层，不会一层层全退。

### Q21: Python 的 pass 语句有什么作用？

`pass` 是个空操作语句，写上去就跟没写一样，解释器遇到它直接跳过，不干任何事。但这个"啥也不干"恰恰是它的价值所在。

你写代码时，有些地方语法上要求必须有语句，但逻辑上又不想处理，比如定义函数或类的时候，还没想好具体实现。这时候你不能空着，Python 会报缩进错误。写个 `pass` 就能占个位置，让结构合法。

1）用在未完成的函数里
```python
def todo_function():
    pass
```

2）用在条件分支的空处理
```python
if flag:
    print("已处理")
else:
    pass  # 暂时不需要处理
```

3）用在类的占位
```python
class MyStubClass:
    pass
```

### Q22: 什么是 Python 中的三元表达式？

Python 中的三元表达式是一种简洁的条件赋值语法，用来在一行内根据条件决定变量的取值。它不是独立的语句，而是一个表达式，能嵌入到其他代码结构中。

写法是：`value_if_true if condition else value_if_false`。程序会先判断 condition，成立就返回前面的值，否则取后面的。

```python
age = 20
status = "adult" if age >= 18 else "minor"
```

这比写完整的 if-else 块紧凑多了，特别适合初始化变量或构造简单逻辑。但别嵌套太多层，像 `A if C1 else B if C2 else D` 这种读起来就费劲了，超过两层最好拆成函数或普通条件语句。

常用于列表推导式里做条件筛选：
```python
numbers = [1, 2, 3, 4]
tags = ["even" if x % 2 == 0 else "odd" for x in numbers]
```

### Q23: Python 中如何实现 switch 语句？

Python 官方直到 3.10 版本才通过 match-case 语法原生支持类似 switch 的结构。在这之前，开发者得靠其他方式模拟。

**3.10+ 的写法：**
```python
def handle_status(code):
    match code:
        case 200:
            return "OK"
        case 404:
            return "Not Found"
        case 500 | 503:
            return "Server Error"
        case _:
            return "Unknown"
```

这个 match-case 不只是值匹配，还能解构数据：
```python
match point:
    case (0, 0):
        print("原点")
    case (x, y) if x == y:
        print(f"在 y=x 线上，位置是 {x}, {y}")
    case (_, _):
        print("二维点")
```

**老版本 Python 常用字典映射函数来模拟：**
```python
def switch_case(status):
    return {
        'start': start_func,
        'pause': pause_func,
        'stop': stop_func
    }.get(status, default_func)()
```

总的来说，简单枚举用字典，复杂模式匹配用 match-case。

## 基础语法

### Q24: Python 的 range 函数如何运用？请举例说明

range 是 Python 里用来生成整数序列的一个内置函数，你压根不需要一次性把所有数放进内存，它只是按规则"算"出下一个值，所以特别省内存。

最常见的用法是配合 for 循环。比如你想打印 0 到 4 的数：
```python
for i in range(5):
    print(i)
# 输出 0, 1, 2, 3, 4。因为 range(5) 表示从 0 开始，到 5 之前结束。
```

你也可以指定起始和结束位置：
```python
for i in range(2, 8):
    print(i)
# 输出 2 到 7
```

还能加步长，比如只取偶数：
```python
for i in range(0, 10, 2):
    print(i)
# 输出 0, 2, 4, 6, 8
```

`range` 生成的是一个可迭代对象，不是列表。如果你真想要列表，得手动转：
```python
list(range(3))  # [0, 1, 2]
```

反向遍历索引时，`range` 就很方便：
```python
items = ['a', 'b', 'c']
for i in range(len(items) - 1, -1, -1):
    print(i, items[i])
```

### Q25: 如何在 Python 中使用多进制数字？

Python 支持直接书写和转换多进制数字，用特定前缀表示进制类型。

二进制以 `0b` 开头，比如 `0b1010` 就是十进制的 10。八进制用 `0o`，像 `0o12` 表示十进制 10。十六进制是 `0x`，`0xA` 还是 10。

如果拿到一个进制字符串想转成十进制，用 `int(str, base)` 函数。例如 `int('1010', 2)` 返回 10，`int('A', 16)` 也是 10。反过来把十进制转其他进制，用 `bin()`、`oct()`、`hex()`，返回对应前缀字符串。

注意别把八进制写成老式前导零风格，比如 `012` 在 Python 3 会报错，必须写成 `0o12` 才行。

```python
print(0b1010)       # 输出 10
print(hex(255))     # 输出 '0xff'
print(int('FF', 16)) # 输出 255
```

不同进制本质都是整数，只是表示方式不同，做计算时压根不经过字符串，直接按补码运算。

### Q26: Python 中单引号和双引号有什么区别？

Python 里单引号和双引号在字符串定义上完全等价，选哪个纯看个人或团队风格。

你写 `'hello'` 还是 `"hello"` 解释器压根不关心，效果一模一样。这一点跟 Java 或 C 不同，Python 并不区分字符和字符串，也没有语法层面的差异。

但实际用的时候，大家会约定一些习惯。比如 JSON 字符串本身有双引号，外面就用单引号包，省得转义：
```python
data = '{"name": "小明", "age": 18}'  # 外层单引号
```

反过来，如果字符串里单引号多，比如英文句子带缩写，外层用双引号更省事：
```python
text = "I can't believe it"
```

f-string 也可以混合使用来少写转义符：
```python
name = "Alice"
f'He said "hi"'  # 外层单引号更清爽
```

总结一下，语法没区别，灵活性才是关键。项目里统一一种风格就行，别来回切换，代码看起来才干净。

### Q27: Python 中怎么注释代码？

Python 里的注释方式其实就三种，用对了能让代码自己说话。

1）**单行注释**用 `#`，后面跟说明文字，这是最常用的：
```python
# 支付超时设为15秒，因为第三方接口最长响应时间是10秒
timeout = 15
```

2）**多行注释**其实没有专门语法，一般用连续的 `#` 行，或者用三引号字符串。注意，三引号 `'''` 或 `"""` 本意是定义多行字符串，不是语言级别的注释，但常被拿来当块注释用，尤其是在函数开头写文档时：
```python
def process_order(order_id):
    """
    处理订单的函数
    参数：order_id 用户订单编号
    返回：处理结果布尔值
    """
    return True
```
这种三引号写法其实就是 docstring，会被 `help()` 和文档工具识别，所以别乱写。

3）注释不是越多越好。变量名能表达意图的，比如 `total_price`，就不用写"这是总价"。真正需要注释的是**"为什么这么做"**，而不是"做了什么"。另外，别把废弃代码用注释"注掉"，版本管理工具才是干这事的。

### Q28: Python 是否有 main 函数？

Python 没有强制的 main 函数，不像 Java 或 C++ 那样要求程序入口必须是 main 方法。脚本从上到下直接执行，哪段代码在顶层就先运行哪段。

但大家常看到 `if __name__ == "__main__":` 这种写法，其实这就是一种约定俗成的 main 入口。当 Python 文件被直接运行时，`__name__` 就会被设为 `"__main__"`；如果是被导入（import），就不会触发这块逻辑。

这个模式主要是为了区分"作为脚本运行"和"作为模块被引用"的场景。

```python
def process():
    print("处理数据")

if __name__ == "__main__":
    process()
```

这样别人 import 你的文件时，`process()` 不会自动执行，只有你自己直接运行这个文件才会走 if 里的逻辑。

所以结论是：Python 没有语法层面的 main 函数，但通过 `__name__` 机制实现了等效的控制能力，属于语言设计上的灵活性体现。

### Q29: 什么是 Python 的负索引？

Python 的负索引是从序列尾部开始倒着数的取值方式。比如最后一个元素用 `-1`，倒数第二个是 `-2`，以此类推。

你写 `my_list[-1]`，拿到的就是列表最后一个元素。这在处理动态长度的数据时特别方便，不用先算 `len(my_list) - 1`。

- `-1` 指向最后一个
- `-2` 指向倒数第二个
- 一直往前推，直到 `-len(seq)`，再小就会越界报错

切片也支持负索引。`my_list[-3:]` 表示从倒数第三个到末尾，`my_list[:-2]` 是从开头到倒数第二个之前的元素。

```python
arr = [10, 20, 30, 40]
print(arr[-1])  # 输出 40
print(arr[-2])  # 输出 30
```

常见场景是取文件路径的最后一级，比如 `path.split('/')[-1]` 拿文件名，或者日志处理时取最近几条记录。超过范围会抛 `IndexError`。

### Q30: Python 在什么情况下会出现 KeyError、TypeError、ValueError？

`KeyError`、`TypeError`、`ValueError` 是 Python 里最常见的三种异常，基本写过几天代码就会遇到。

**KeyError** 出现在你试图从字典里拿一个不存在的键。比如 `d = {'a': 1}; print(d['b'])`，直接报 KeyError。处理办法一般是用 `.get()` 方法提供默认值，或者先用 `in` 判断键是否存在。
```python
d.get('b', 0)  # 安全访问，没找到返回 0
```

**TypeError** 是类型搞错了。典型场景是把字符串和数字相加 `1 + '2'`，或者把不可哈希的对象当字典 key 用，比如列表 `d[[1,2]] = 3`。还有一种是函数调用时参数类型不对，比如 `len(123)`。

**ValueError** 是类型对了，但值不合法。比如你调 `int('abc')`，字符串看着不像数字，转不了；或者 `json.loads('{'key')` 解析坏格式 JSON。还有像 `math.sqrt(-1)` 这种数学上不成立的操作，默认也会抛 ValueError。

简单记：
1）找键找不到 → KeyError
2）类型用错 → TypeError
3）值不合规 → ValueError
