## Python 中如何读取大文件，例如内存只有 4G，如何读取一个大小为 8G 的文件

> 主要是不要一次性将整个文件加载到内存中，如使用`read()`或`readlines()`，核心解决方法是：分块读取、逐行读取、使用生成器等

- 分块读取：适合文本文件

```python
with open('large_file.txt', 'r') as f:
    for line in f:
        # 处理每一行，不保留所有行
        process_line(line)
```

> 原理：文件对象 `f` 在迭代时内部使用缓冲区，每次返回一行，内存中只保存当前行的内容。

- 固定大小块读取：适用于二进制文件或不需要按行分割的场景

```python
def read_in_chunks(file_path, chunk_size=1024*1024):  # 1MB 的块
    with open(file_path, 'rb') as f:
        while True:
            chunk = f.read(chunk_size)
            if not chunk:
                break
            # 处理该数据块
            process_chunk(chunk)
```

- 使用 `mmap` 内存映射：适合随机访问大文件
- 使用生成器

```python
def file_chunk_generator(file_path, chunk_size=1024*1024):
    with open(file_path, 'rb') as f:
        while True:
            chunk = f.read(chunk_size)
            if not chunk:
                break
            yield chunk

for chunk in file_chunk_generator('huge_file.bin'):
    process_chunk(chunk)
```
