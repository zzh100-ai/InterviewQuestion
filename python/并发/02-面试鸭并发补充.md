### Q3: 2189. 请介绍 Python 中多线程和多进程的应用场景，以及优缺点？

**难度**: 中等  

使用多线程和多进程是为了提高程序的并发性能。多线程适合 I/O 密集型任务，而多进程则更适合 CPU 密集型任务。

1）多线程（Threading）：

应用场景：主要用在 I/O 密集型任务中，比如文件读写、网络请求和数据库操作。由于这些任务主要受限于 I/O 操作时间，多线程可以在等待 I/O 操作完成的同时，执行其他操作，提升程序的并发能力。

线程之间共享内存空间，通信成本低。 ...
